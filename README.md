# 自动刷课脚本 (Auto Learn Script)

这是一个运行在浏览器控制台（Console）中的 JavaScript 自动化脚本，旨在帮助用户自动完成在线网课的学习任务。该脚本能够智能识别视频、文档材料和普通页面，并自动进行播放、点击查看和章节跳转。

## ✨ 主要功能

- **全自动流程**：自动遍历所有章节和子章节，无需人工干预。
- **智能视频处理**：
  - 自动寻找页面中面积最大的视频进行播放。
  - 支持自定义播放倍速（`VIDEO_PLAYBACK_RATE`）。
  - **静音播放**：自动静音以绕过浏览器的自动播放限制。
  - **防卡死机制**：内置看门狗（Watchdog），检测进度长时间无变化时自动跳过。
  - **精准结束检测**：通过检测播放进度比例或 `ended` 事件来判断视频是否完成。
- **文档/材料处理**：自动点击“查看”按钮，并在短暂浏览后自动关闭预览窗口。
- **断点续刷**：脚本启动时会自动检测当前高亮的章节/项目，从该位置继续执行，而不是每次都从头开始。
- **日志输出**：控制台输出日志，清晰整洁。
- **健壮性设计**：点击元素前自动滚动到可视区域，防止因遮挡导致的点击失败。

## 🚀 如何使用

1. **打开网课页面**：  
   在浏览器（推荐 Chrome 或 Edge）中打开你的网课学习页面，并进入课程目录界面。

2. **打开开发者工具**：  
   按下 `F12` 键，或者右键点击页面空白处选择“检查（Inspect）”。

3. **切换到控制台**：  
   在开发者工具面板中点击 **Console**（控制台）标签。
   
   > ⚠️ **注意**：如果侧边栏是在 `iframe` 中，请务必在 Console 顶部的下拉菜单中选择对应的 iframe 上下文（通常不是 `top`）。

4. **注入脚本**：  
   复制脚本代码，粘贴到控制台中，然后按下 `Enter` 键执行。

5. **开始运行**：  
   脚本将立即开始工作，你可以在控制台中看到实时的英文运行日志。

## ⚙️ 配置说明 (Configurations)

你可以在脚本顶部的 `CONFIG` 对象中修改以下参数以适应不同的网络环境或需求：

| 参数名                       | 默认值     | 说明                                     |
| ------------------------- | ------- | -------------------------------------- |
| `VIDEO_PLAYBACK_RATE`     | `1.0`   | 视频播放倍速（建议 1.0 或 1.5，过高可能导致记录失败）。       |
| `DEFAULT_WAIT_TIME`       | `7000`  | 处理普通页面或点击后的默认等待时间（毫秒）。                 |
| `POLLING_INTERVAL`        | `1000`  | 检测视频状态的轮询间隔（毫秒）。                       |
| `SUB_SECTION_EXPAND_WAIT` | `2000`  | 展开子章节后的等待时间（毫秒）。                       |
| `WAIT_AFTER_VIDEO_MS`     | `60000` | **重要**：视频播放结束后的额外挂机时间（毫秒），防止切换过快不记录进度。 |
| `VIDEO_FINISH_THRESHOLD`  | `0.995` | 视频播放进度的完成阈值（例如 0.995 代表 99.5%）。        |
| `VIDEO_IDLE_TIMEOUT_MS`   | `45000` | 视频进度无增长的超时判定时间（毫秒），超过则视为卡死并跳过。         |

## 🛑 停止脚本

如果在运行过程中需要强制停止脚本，请在控制台中输入以下命令并回车：

```javascript
window.stopAutoLearn()
```

*脚本会在当前正在执行的步骤完成后（例如等完当前视频）停止运行。*
